# AI Roleplay Chat v2.5.2

本次修复手机创建窗口的文字截断，并将界面调整为更轻快、克制的灰蓝风格。

## 变化

- 降低消息气泡、按钮、选中项和背景渐变的色彩强度；减弱毛玻璃高光，正文仍保持清晰可读。浅色和深色主题同步调整。
- “表单创建 / 使用 JSON 创建 / 使用自然语言创建”移到表单顶部，根据可用宽度自动换行，长标签完整显示。
- 创建窗口取消固定最小宽高，随屏幕、安全区域和键盘收缩，表单可滚动，取消与创建按钮保持可点击。
- 聊天顶部随系统字体大小增加高度；横屏或键盘弹出时，输入框减少显示行数，内容仍可滚动编辑。

## 验证

- Flutter 静态分析通过，387 项自动测试全部通过。
- 创建窗口覆盖 320×568、360×640、390×844、412×915、540×720、640×360、844×390 逻辑像素，分别验证 1.0、1.3、1.6 倍字体，以及键盘弹出后输入、提交。
- 聊天、侧栏与资料页覆盖小屏、长屏和横屏、大字体、键盘及安全区域的组件测试；使用真实中文字体渲染预览。
- Android 版本 2.5.2，versionCode 12。手机适配验证来自 Flutter 组件测试，本次未进行 Android 实机测试。
- APK v2 签名验证通过，交付文件与构建输出 SHA-256 一致：`d02ed8ee3dfc9c1c7d89fe66f7214b4c7304b01258e9d1e29cb951ae54562daf`。
