# AI Roleplay Chat v2.5.1

本次更新整合 v2.3.0 之后的剧情连续性、提示词组织、手机交互与资料编辑改进。

## 主要变化

- 统一浅色/深色主题、圆角分组和导航/消息动效。输入栏、侧栏和身份卡片加入局部毛玻璃；模型切换收进“聊天操作 → 切换模型”底部面板。
- 点击顶部信息栏、会话头像或侧栏头像，编辑名字、角色设定、状态、知识和物品。支持 JPG/JPEG、PNG、WebP 照片头像，自动缩小并随本地备份保存。
- 修复手机 API 提供商入口和输入焦点。每个 API Profile 可独立设置输出上限与 JSON 响应模式。
- JSON 创建兼容常见字段别名、全半角标点和空格，给出具体字段、行列和出错字符，导入前展示调整结果。
- 提示词按运行契约、角色/世界配置、状态和本轮上下文分层。最近对话使用原生 user/assistant 消息；v5 响应先输出正文，再输出记忆变更。知识与物品支持新增、替换和删除。
- 用户定义故事状态；完整轮次通过 SQLite 事务提交。撤回、修改后重发、历史删除、分支及备份保留可恢复的剧情状态，支持重启后连续撤回。

## 验证与安装

- Flutter 静态分析通过，362 项自动测试全部通过。
- Android 版本 2.5.1，versionCode 11；最低 Android 8.0（API 26）。
