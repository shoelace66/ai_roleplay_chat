# v2.5.0 · 手机界面与资料编辑

所有页面共享浅灰/深灰背景、柔和蓝色、圆角卡片、统一表单、分组标签和按钮样式，跟随系统浅色/深色设置。手机页面使用滑入返回过渡，最新消息淡入并轻微上移，发送/停止按钮切换过渡；消息与输入指示动效尊重系统“减少动态效果”设置。

## 编辑入口

点击聊天最上方的头像或名称栏目、回复旁的角色头像、侧栏角色头像，进入同一资料页。

- **资料**：名字、照片、音色 ID、固定输入、性格、外貌、个人信息、背景故事、叙事规则、其他特征、关联设定。
- **状态**：所有用户定义的状态名称、说明、初值、更新规则和当前值，可新增、排序、删除；也可修改旧数据中的情绪、时间和其他状态标签。
- **记忆**：完整世界知识、自我认知、用户认知、物品，可修正或删除。未编辑的多行知识原样保留。

离开未保存的资料会提示保留编辑或放弃修改。保存失败时继续保留草稿；生成期间禁止修改，过期角色/分支快照不能覆盖新数据。联系人修改通过现有持久化事务保存，成功后再更新界面；聊天消息和事件图不会被资料页重建。

## 照片

创建角色和修改资料都支持系统文件选择器，接受 JPG/JPEG、PNG、WebP，最大 20 MB。应用真实解码图片，按比例缩小至最长边 512 像素，保存便携 PNG 数据；侧栏、聊天顶部、消息头像共享缓存渲染。照片随联系人进入 SQLite 和备份，不依赖系统临时文件路径，损坏图片提供可读错误。
